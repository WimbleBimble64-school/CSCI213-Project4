# CSCI213-Project4
# Transportation Final Cost Calculator
# Author: Joshua Bodde
## What does this project supposed to do?
This project is supposed to take the collective results of the total cost (including discounts) and return them to the user for them to decide what mode of transport they would like to go on


---
## What does this project have?
- Calculates cost for
  - Car (Single or Round Trip)
  - Bus (Single or Round Trip)
  - Train (All day pass)
 
- Applies the discounts
    - 50% for kids (0 - 17)
    - 30% for seniors (65+)
    - 15% Electric Vehicle choice
 
- Determines the cheapest mode of transport for the user
- JavaFX is used for user interactivity

---
